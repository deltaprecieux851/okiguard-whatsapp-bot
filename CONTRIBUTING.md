Contribution

Merci pour ton intérêt à contribuer !

- Fork le repo et crée une branche feature/xxx
- Respecte le style existant et écris des tests simples pour les nouvelles fonctionnalités
- Exécute `npm test` avant de proposer une PR
- Pour des changements importants, ouvre une issue d'abord pour discussion

Code review: je répondrai aux PR et aux issues. Merci d'ajouter des tests et de la documentation pour chaque changement non trivial.
